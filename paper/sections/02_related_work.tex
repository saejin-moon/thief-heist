\section{Related Work}
\label{sec:related}

\paragraph{Cooperative Multi-Agent RL.}
Decentralized cooperative MARL has evolved around value factorization and policy gradient architectures within the CTDE paradigm. Value-Decomposition Networks (VDN)~\cite{sunehag2018value} and QMIX~\cite{rashid2020monotonic} enforce monotonic value factorization across joint action-value functions. Multi-Agent PPO (MAPPO)~\cite{yu2022surprising} leverages centralized value functions to stabilize decentralized actor updates, demonstrating competitive performance across diverse benchmarks. Counterfactual Multi-Agent Policy Gradients (COMA)~\cite{foerster2018counterfactual} isolates individual agent contributions via counterfactual baselines marginalizing single-agent actions. Hierarchical approaches such as FeUdal Networks~\cite{vezhnevets2017feudal} introduce multi-scale manager-worker policies. While these methods demonstrate high performance in symmetric combat and mobility, they operate on fixed network capacities and succumb to representation collapse when heterogeneous agents encounter temporally mismatched reward densities.

\paragraph{Mixture of Experts in Deep RL.}
Sparsely-gated Mixture of Experts (MoE)~\cite{shazeer2017outrageously,fedus2022switch,lepikhin2020gshard} routes input tokens through subsets of feed-forward sub-networks via learned gating functions. In reinforcement learning, MoE architectures have been applied to multi-task generalization and hierarchical skill partitioning. However, value-bidding routing in MARL suffers from the ``rich-get-richer'' pathology: an incumbent generalist possessing an established critic baseline monopolizes routing tournaments, starving emerging specialist sub-networks. THIEF eliminates this collapse by pairing isolated sandbox incubation with explicit auxiliary load-balancing losses and hysteresis barriers.

\paragraph{Evolutionary RL and Parameter Distillation.}
Evolutionary strategies (ES) and population-based training~\cite{salimans2017evolution,clune2019ai,stanley2019open} optimize neural policies through stochastic parameter exploration. Parameter recombination using Fisher Information geometry~\cite{amari1998natural,kirkpatrick2017overcoming} enables distillation of parameter manifolds without catastrophic forgetting of historical capabilities. In this work, we contrast THIEF against E-COOP, an evolutionary MARL baseline that performs periodic Fisher recombination into a single champion. THIEF fundamentally advances beyond E-COOP by treating experts as dynamic, open-ended functional modules spawned on empirical win-rate plateaus and preserved via balanced routing.
